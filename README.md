# 🍉 Math Suika Game

작은 과일을 상자에 떨어뜨려 **값이 같은** 과일끼리 닿게 하면 더 큰 과일로 변하는 수박 게임(Suika Game)입니다.
과일에는 숫자 대신 식이 적혀 있어서, `6+6` 과 `3×4` 처럼 모양은 달라도 값이 같은 것을 찾아야 합니다.
초등학교 2~4학년 **창의 수학**을 게임으로 익히도록 만들었습니다.

## 지금 되는 것

- 물리 수박 게임 (Matter.js): 낙하, 합체, 게임오버 라인, 다음 과일 미리보기
- **월드 6개** — 같은 값 2개가 닿으면 다음 단계가 되고, 월드마다 값의 종류가 다릅니다

  | 월드 | 학년 | 사다리 | 과일에 적힌 것 |
  |---|---|---|---|
  | 🌳 더블 숲 | 2 | 2 → 4 → … → 1024 | `6+6`, `3×4`, `20−8`, `2×4+5` |
  | 📏 길이 마을 | 2~3 | 10cm → … → 12m 80cm | `1m 20cm`, `60cm+60cm`, `2×20cm`, `1m−40cm` |
  | ⏰ 시계탑 | 2~3 | 15분 → … → 16시간 | `1시간 30분`, `45분+45분`, `2시간−30분` |
  | 🍕 분수 연못 | 3~4 | 1/8 → … → 16 | `2/4`, `1/8+1/8`, `5/4−3/4`, `0.5` (분수는 위아래로 쌓아서 표시) |
  | ⛰️ 큰 수 산 | 4 | 5백 → … → 12만 8천 | `1만 6천`, `8,000+8,000`, `4×4천` |
  | 📐 각도 성 | 4 | 5° → … → 320° | `90°−50°`, `180°−70°−70°`, `360°−40°` |

- **🗺️ 모험 모드**: 월드마다 스테이지 5개, 앞 스테이지를 깨야 다음이 열립니다. 스테이지마다 목표가 있고 ⭐을 최대 3개 받습니다.

  | 스테이지 | 목표 | 과일 힌트 |
  |---|---|---|
  | 1 첫걸음 | 4단계 과일 만들기 | 쉬움 |
  | 2 생각 주머니 | 퀘스트 2개 맞히기 | 쉬움 |
  | 3 쑥쑥 자라는 과일 | 5단계 과일 만들기 | 보통 |
  | 4 생각왕 | 힌트 없이 퀘스트 3개 맞히기 | 보통 |
  | 5 보스 과일 | 7단계 과일 + 퀘스트 2개 | 어려움 |

  ⭐1 클리어 · ⭐2 힌트 없이 퀘스트를 맞힘 · ⭐3 정해진 개수 이하의 과일로 클리어. 월드 카드에 모은 별(⭐ n/15)이 표시됩니다.
- **♾️ 자유 모드**: 목표 없이 끝없이, 사용자가 정한 힌트 단계로 점수를 겨룹니다.
- 힌트 단계 설정(자유 모드): 쉬움(과일 종류가 단계를 알려줌) / 보통 / 어려움(긴 식). 작은 과일에는 짧은 식만 들어갑니다.
- 🎁 **미스터리 퀘스트 (문제은행)**: 합체 5~8번마다 창의 수학 문제가 나옵니다. 힌트 3단계, 시간제한 없음.
  - 문제 틀 **88개**: 손으로 쓴 고정 문제 43개 + **숫자와 상황이 매번 바뀌는 문제 생성기 45종** → 실제로 나오는 문제는 수천 가지입니다. 스테이지마다 문제가 정해져 있지 않고 은행에서 랜덤으로 뽑습니다.
  - 뽑는 기준: 학년 설정 · 지금 월드와 어울리는 주제(3배) · 모험 스테이지의 난이도(쉬움 → 어려움) · 안 풀어 본 주제와 자주 틀리는 주제 · 최근에 나온 문제는 피하기
  - 주제: 식 만들기, 규칙 찾기, 논리, 경우의 수, 수 만들기, 곱셈·나눗셈, 시간, 길이, 분수, 큰 수, 각도
- 📦 **오답 상자**: 틀린 문제를 **숫자까지 그대로** 저장해 두었다가 퀘스트 2·5·10번 뒤에 다시 냅니다(복습할 때가 된 오답은 퀘스트 중 절반쯤 다시 나옴). 힌트 없이 한 번에 3번 연속 맞히면 🎓 졸업. 시작 화면의 📦 에서 목록을 보고 게임 없이 5문제씩 복습할 수도 있습니다.
- 👪 **부모 리포트** (시작 화면 아래 `👪 부모님`, PIN으로 보호): 요약(오늘·이번 주 시간, 푼 문제 수, 힌트 없이 한 번에 맞힌 비율, 최근 7일 막대 그래프, 부모를 위한 제안), 단원별 현황(잘해요/보통/연습이 필요해요), 오답 상자와 모험 진행, 설정
  - **하루 놀이 시간 제한**(20~90분): 실제로 놀이한 시간만 재고(메뉴·일시정지는 제외), 5분 전에 알려주고, 시간이 다 되면 잠금 화면이 뜹니다. 부모가 PIN을 입력하면 15분씩 늘려 줄 수 있어요. 시간 제한을 걸려면 PIN이 먼저 필요합니다.
  - 퀘스트 학년 조정, PIN 만들기/바꾸기, 기록 **내보내기(파일·복사)와 가져오기**, 모든 기록 지우기
  - 기록은 이 기기의 브라우저(`localStorage`)에만 저장되고 어디로도 전송되지 않습니다. PIN은 해시로 저장되지만 "아이가 실수로 열지 않게 하는 잠금"이며 강한 보안은 아닙니다(사이트 데이터를 지우면 PIN도 사라짐).
- 📲 **앱처럼 설치 + 오프라인 (PWA)**: 갤럭시(크롬·삼성 인터넷)에서 시작 화면의 `📲 홈 화면에 추가` 버튼(또는 브라우저 메뉴 ▸ 홈 화면에 추가)으로 설치하면 전체 화면 앱처럼 열립니다. 처음 한 번 열어 두면 그림·글꼴·문제를 모두 저장해서 **비행기 모드에서도** 할 수 있어요(`✅ 인터넷이 없어도 할 수 있어요` 표시). 새 버전이 나오면 시작 화면에 `🔄 새 버전으로 바꾸기`가 떠서, 하던 판이 갑자기 새로고침되지 않습니다. 아이폰은 공유 ▸ 홈 화면에 추가.
- 아이템: 🔍 힌트 · 💣 폭탄 · 🌀 흔들기 · ⏪ 되돌리기 (퀘스트를 풀면 획득)
- 월드별 최고 점수와 주제별 정답률 기록 (`localStorage`) → 덜 본 주제, 틀린 주제를 더 자주 출제
- 갤럭시 화면(360×740 ~ 412×915)에서 확인

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 식 생성기(월드별) / 문제 생성기(정답 재계산) / 문제은행 / 오답 상자 / 모험 규칙
npm run build   # dist/ 생성 (GitHub Pages 배포용)
```

`main` 브랜치에 푸시하면 GitHub Actions가 Pages로 배포합니다 (레포 Settings → Pages → Source: GitHub Actions).

## 구조

```
src/
  game/      물리, 합체, 게임오버, 그리기 (Game.ts, render.ts, config.ts)
  math/      식 계산(evaluate.ts), 식 생성(expr.ts: 정수, labels.ts: 길이·시간·각도·큰 수·분수)
  content/   월드 정의(worlds.ts), 고정 문제(quests.ts), 문제 생성기(generators.ts), 문제은행·뽑기(bank.ts), 스테이지 규칙(adventure.ts)
  새 월드는 worlds.ts 의 WORLDS 에 한 항목을 더하면 됩니다 (사다리, 식 생성기, 표기 함수)
  state/     localStorage 저장(storage.ts), 오답 상자 규칙(wrongbox.ts), 리포트 집계·시간 제한(report.ts), PIN(pin.ts)
  pwa.ts     설치 버튼 · 오프라인 준비 · 새 버전 알림
  ui/        퀘스트 카드, 모험 모드 화면(스테이지 지도·안내·클리어), 오답 상자 화면, 부모 리포트(parent.ts)
docs/DESIGN.md   전체 설계안
```
