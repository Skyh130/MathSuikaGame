# 🍉 Math Suika Game

작은 과일을 상자에 떨어뜨려 **값이 같은** 과일끼리 닿게 하면 더 큰 과일로 변하는 수박 게임(Suika Game)입니다.
과일에는 숫자 대신 식이 적혀 있어서, `6+6` 과 `3×4` 처럼 모양은 달라도 값이 같은 것을 찾아야 합니다.
초등학교 2~4학년 **창의 수학**을 게임으로 익히도록 만들었습니다.

## 지금 되는 것

- 물리 수박 게임 (Matter.js): 낙하, 합체, 게임오버 라인, 다음 과일 미리보기
- **월드 6개** — 같은 값 2개가 닿으면 다음 단계가 되고, 월드마다 값의 종류가 다릅니다

  | 월드 | 학년 | 사다리 | 과일에 적힌 것 |
  |---|---|---|---|
  | 🌳 더블 숲 | 2 | 2 → 4 → … → 1024 | `6+6`, `3×4`, `20−8`, `2×4+5` |
  | 📏 길이 마을 | 2~3 | 10cm → … → 12m 80cm | `1m 20cm`, `60cm+60cm`, `2×20cm`, `1m−40cm` |
  | ⏰ 시계탑 | 2~3 | 15분 → … → 16시간 | `1시간 30분`, `45분+45분`, `2시간−30분` |
  | 🍕 분수 연못 | 3~4 | 1/8 → … → 16 | `2/4`, `1/8+1/8`, `5/4−3/4`, `0.5` (분수는 위아래로 쌓아서 표시) |
  | ⛰️ 큰 수 산 | 4 | 5백 → … → 12만 8천 | `1만 6천`, `8,000+8,000`, `4×4천` |
  | 📐 각도 성 | 4 | 5° → … → 320° | `90°−50°`, `180°−70°−70°`, `360°−40°` |

- 힌트 단계 설정: 쉬움(과일 종류가 단계를 알려줌) / 보통 / 어려움(긴 식). 작은 과일에는 짧은 식만 들어갑니다.
- 🎁 미스터리 퀘스트: 합체 5~8번마다 창의 수학 문제 43개 (식 만들기, 규칙 찾기, 논리, 경우의 수, 수 만들기, 시간, 길이, 분수, 큰 수, 각도). 힌트 3단계, 시간제한 없음. 지금 하는 월드와 어울리는 주제를 더 자주 냅니다.
- 아이템: 🔍 힌트 · 💣 폭탄 · 🌀 흔들기 · ⏪ 되돌리기 (퀘스트를 풀면 획득)
- 월드별 최고 점수와 주제별 정답률 기록 (`localStorage`) → 덜 본 주제, 틀린 주제를 더 자주 출제
- 갤럭시 화면(360×740 ~ 412×915)에서 확인

## 실행

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # 식 생성기(월드별) / 계산기 / 문제 은행 단위 테스트
npm run build   # dist/ 생성 (GitHub Pages 배포용)
```

`main` 브랜치에 푸시하면 GitHub Actions가 Pages로 배포합니다 (레포 Settings → Pages → Source: GitHub Actions).

## 구조

```
src/
  game/      물리, 합체, 게임오버, 그리기 (Game.ts, render.ts, config.ts)
  math/      식 계산(evaluate.ts), 식 생성(expr.ts: 정수, labels.ts: 길이·시간·각도·큰 수·분수)
  content/   월드 정의(worlds.ts), 퀘스트 문제 은행(quests.ts)
  새 월드는 worlds.ts 의 WORLDS 에 한 항목을 더하면 됩니다 (사다리, 식 생성기, 표기 함수)
  state/     localStorage 저장
  ui/        퀘스트 카드
docs/DESIGN.md   전체 설계안
```
