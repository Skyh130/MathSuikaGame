# Math Suika Game 설계안

## 컨셉
같은 모양이 아니라 **같은 값**일 때 합쳐지는 수박 게임. 과일에는 `3×4`, `6+6`, `20−8` 같은 식이나 그림이 적혀 있고,
값이 같은 두 과일이 닿으면 다음 단계(예: ×2)로 합쳐진다. 크기와 색이 정답을 알려주지 않도록 힌트 단계를 둔다.

| 힌트 단계 | 방식 |
|---|---|
| 쉬움 | 색이 단계를 알려줌, 짧은 식 |
| 보통 | 색은 무작위, 세 수의 식도 섞임 |
| 어려움 | 색은 무작위, 세 수의 식 위주 (쌍둥이 함정 값은 추후) |

## 월드 (합체 규칙)
| 월드 | 학년 | 사다리 | 과일에 적힌 것 | 상태 |
|---|---|---|---|---|
| 더블 숲 | 2 | 2→4→…→1024 | 덧셈·뺄셈·곱셈 식 | ✅ |
| 길이 마을 | 2~3 | 10cm→…→12m 80cm | `1m 20cm`, `60cm+60cm` | ✅ |
| 시계탑 | 2~3 | 15분→…→16시간 | `1시간 30분`, `45분+45분` | ✅ |
| 분수 연못 | 3~4 | 1/8→…→16 | `2/4`, `1/8+1/8`, `0.5` | ✅ (그림 없이 식만) |
| 큰 수 산 | 4 | 5백→…→12만 8천 | `1만 6천`, `8,000+8,000` | ✅ |
| 각도 성 | 4 | 5°→…→320° | `180°−70°−70°` | ✅ (각도기 그림은 예정) |
| 짝꿍 합체 | 2~4 | 합이 10/100/1000 | 보수 | 예정 |

## 창의 수학 퀘스트
합체 5~8번마다 카드가 뜨고, 물리는 일시정지, 시간제한 없음. 오답에 벌점 없이 힌트 3단계(방향 → 일부 → 전체) + 해설.
유형: 식 만들기, 규칙 찾기, 논리·저울, 경우의 수, 수 만들기, 간격, 시각과 시간. 보상은 아이템.

## 문제은행
- 문제 틀(template) = 고정 문제 43 + 생성기 45. 생성기는 숫자·상황을 바꿔 정답, 힌트 3단계, 해설을 함께 만든다.
- 출제는 월드·학년·난이도·약한 단원 가중치로 랜덤 (`bank.ts`). 스테이지에 문제가 묶여 있지 않다.
- 난이도 1~3: 모험에서는 스테이지의 힌트 단계(쉬움/보통/어려움)와 맞춘다.

## 오답 상자
- 틀린 문제를 그대로 저장(생성 문제도 같은 숫자로), 간격 반복: 2 → 5 → 10번 뒤, 깔끔하게 3번 맞히면 졸업.
- 게임 중 복습 대상이 있으면 퀘스트의 절반쯤을 그것으로 낸다. 별도 복습 화면(5문제씩)도 있다.

## 모드
- ✅ 모험: 월드마다 스테이지 5개(첫걸음 → 생각 주머니 → 쑥쑥 → 생각왕 → 보스), ⭐ 최대 3개. 힌트 단계가 스테이지마다 올라간다.
- ✅ 자유: 목표 없이 끝없이.
- 예정: 오늘의 도전(같은 시드), 오답 연습.

## 적응형 난이도 (예정)
단원별 숙련도(정답률, 힌트 수, 풀이 시간) 기반. 현재는 주제별 정답률로 출제 가중치만 조정.

## 학부모 (예정)
PIN 화면, 학년 범위, 하루 시간 제한, 단원별 리포트. 서버 없이 `localStorage`, JSON 내보내기/가져오기.

## 기술
Vite + TypeScript + Matter.js + Canvas 2D, 모바일 세로 우선, GitHub Pages 배포. 값 비교는 정수(분수 월드부터 유리수).

## 개발 단계
M0 세팅 ✅ · M1 물리 수박 게임 ✅ · M2 값 기반 합체 + 더블 숲 ✅ · M3 퀘스트 카드 ✅(1차) · M4 월드 확장 ✅ · 모험 모드 ✅ · M5 숙련도·오답 상자·부모 화면·PWA · M6 플레이 테스트
